# UrbanEdge AI Real Estate Assistant

An AI-powered real estate lead qualification system designed for buyers, sellers, and investors.

This project combines conversational AI, workflow automation, and CRM integration to help real estate businesses automate lead collection and qualification.

---

## Features

- AI-powered property assistant
- Buyer, seller, and investor qualification flows
- Automated lead collection
- Airtable CRM integration
- Make.com automation workflows
- Lead classification (Hot / Warm / Cold)
- Responsive premium landing page
- Voiceflow chatbot integration
- Deployable on websites and landing pages

---

## Technologies Used

- HTML5
- CSS3
- Voiceflow
- Make.com
- Airtable
- Netlify
- GitHub

---

## How The System Works

1. User interacts with AI assistant
2. AI collects lead information
3. Workflow automation processes data
4. Leads are routed through Make.com
5. Airtable CRM stores structured records
6. Sales team can follow up instantly

---

## Project Purpose

This project was created as a portfolio-ready AI automation system for real estate businesses.

The goal was to simulate a real client deployment workflow including:
- frontend landing page
- AI assistant integration
- CRM automation
- deployment-ready infrastructure
